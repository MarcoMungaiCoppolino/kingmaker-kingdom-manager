Kingmaker Kingdom Manager — Linux

Extract this folder anywhere you can write to (your home is fine), then run
./kingmaker-kingdom-manager: the launcher window opens. Your game is kept in
saves/ and assets/ inside this same folder. Needs Ubuntu 22.04 or newer (or
another distribution with glibc 2.35+).

On a desktop nothing else is needed. On a bare system — a server, a
container, WSL — the launcher window wants the X screensaver library,
which such a system usually does not carry:

    sudo apt install libxss1         (Debian, Ubuntu)
    sudo dnf install libXScrnSaver   (Fedora, RHEL)

To have it in your applications menu, with its name and icon in the dock or
taskbar (GNOME, KDE and the others), run this once from inside this folder:

    mkdir -p ~/.local/share/applications
    sed -e "s|^Exec=.*|Exec=\"$PWD/kingmaker-kingdom-manager\"|" \
        -e "s|^Icon=.*|Icon=$PWD/_internal/icon/kingmaker.png|" \
        kingmaker.desktop > ~/.local/share/applications/kingmaker.desktop

Moved the folder? Run it again from the new place.

To uninstall, delete the folder (and ~/.local/share/applications/kingmaker.desktop,
if you made it). To update, extract the new version over it:
saves/ and assets/ are untouched. The launcher keeps its secrets (the cloud
access, the On Air token) in ~/.local/share/kingmaker-kingdom-manager/secrets/,
readable by you alone: delete that folder too when this PC leaves the table.

Terminal users: ./kingmaker-kingdom-manager --serve [--lan] [--online] runs
the server without the window, with the same flags as launch.py.
